# AxisBridge 0.1.1

Slate 7 calibration improvements and optional plug-in-and-run output.

## Changes

- Corrected Slate 7 touchscreen contact/release handling and left/right touch mapping.
- Both **Update Low** and **Update High** work during live output after a continuous four-second hold. Release or slide away to cancel.
- Each button skips selected blocks already at either saved endpoint, preserving their calibration while saving the other selected blocks. The screen reports saved/skipped counts. Disabled or stale selected blocks still prevent a capture.
- Screen block selections can be changed while output remains live.
- Added **Enable output automatically after MA login**. With saved auto-connect enabled, the bridge starts PSN, reconnects MA, and enables output after successful authentication without a browser or portal login. This option is off by default on new installs; existing saved preferences are preserved.
- Manual Hold stays held until the next successful MA login or manual arming. Stale or uncalibrated blocks never send fader commands.
- Retained change-driven output with a ten-second refresh while input remains fresh.
- The Intel Mac launcher preserves space-only portal keys and accurately describes the saved automatic-output setting.

## Downloads

The release includes fresh Intel Mac and Windows x64 applications, portable Python source for macOS/Windows/Raspberry Pi, and the GL.iNet Slate 7 GL-BE3600 SSH installer with its quick-start guide. The Slate archive is **not router firmware**.

The Intel Mac app requires macOS 13 or newer and is ad-hoc signed, not Apple-notarized. The Windows executable is not Authenticode-signed.

## Verification and upgrade notes

- 59 application tests and 11 installer tests passed locally, including live partial capture, unchanged-block preservation, no-op holds, input loss, login/reconnect behavior, integrity checks, and rollback.
- The Slate implementation was installed on physical GL-BE3600 hardware. Touch recognition, four-second capture, MA login, and demo-to-MA transport were observed. Both skip-and-save paths were also checked using isolated test shows on the router.
- Actual Raynok acceptance and physical console fader/parameter readback remain operator checks. Last-sent values report commands transmitted, not console state.
- Upgrading preserves the saved show, access key, MA password, and router network settings. The service restarts during an upgrade. With automatic output enabled, fader output can resume after MA authenticates.

Normal operation needs no web login once configured. The portal remains protected for setup and edits. No device-specific credentials or saved shows are included in the release.
