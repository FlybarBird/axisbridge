# Verification — AxisBridge 0.1.0

Verified in the development environment on 2026-09-22.

## Passed

- **31 Python tests**: `python -m unittest discover -s tests -v`.
- Real PSN UDP unicast reception bound to a selected local IPv4 address.
- Real PSN multicast reception on the selected loopback interface.
- TCP fader output bound to a different local IPv4 address (Linux loopback aliases 127.0.0.2 and 127.0.0.3 were used to verify independent socket binding).
- Mock grandMA2 login, including fragmented acknowledgement, rejected credentials, disconnect, reconnect, and manual re-arm requirement.
- Bottom/top capture at 0 and 10; midpoint drives two assigned faders to 50%; later position 7.5 drives 75%.
- Stale-data hold, resumed current-position output, explicit Hold, reversed ranges, smoothing, and command deadband.
- Reference packets generated by VYV's C++ PSN encoder: 150 trackers, four data datagrams, two info datagrams, XYZ and orientation.
- Portal browser test in Chromium: login, demo signals, block creation, live bottom/top capture, multiple targets, monitor, network save, show persistence after reload, phone-width layout, editor, and demo exit.
- Live demo-to-MA output, owner-only password persistence, saved PSN/MA auto-connect settings, and startup safety hold.
- Desktop/mobile screenshots inspected. A demo-slider display reset after browser reload was found and fixed, and the portal test was rerun successfully.
- GitHub native builds passed all 31 tests on both `macos-15-intel` and Windows x64 runners.
- The Intel Mac app contains x86_64 launcher/service Mach-O binaries; its ad-hoc bundle signature passed strict verification.
- The Windows app is a PE32+ x86-64 executable and passed its command-line startup smoke check on Windows.

## Not verified here

- Actual Raynok output, its version/configuration, units, and field availability.
- A physical grandMA2 console or onPC, executor options, physical fader movement, and parameter output.
- macOS, Windows, or Raspberry Pi hardware and their network drivers/firewalls.
- Apple notarization, Authenticode signing, or signed installers.
- Sustained load with the maximum permitted number of blocks/targets.

The portal reports the last commands sent, not console fader readback. Hardware acceptance testing remains required before using this release during a show.
